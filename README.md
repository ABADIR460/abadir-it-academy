# Abadir IT Academy Website

Static, GitHub Pages-ready website for Abadir IT Academy.

## Publish on GitHub Pages
1. Create a **Public** GitHub repository.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Open the generated `https://USERNAME.github.io/REPOSITORY/` URL.

## Before publishing
Open `script.js` and replace:
`const WHATSAPP_NUMBER='251956144830';`
with the real WhatsApp number in international format, without `+` or spaces.
